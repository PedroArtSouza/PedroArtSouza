## 🧭 Quem sou

Sou desenvolvedor com interesse em construir soluções que conectam **aplicações mobile, interfaces web, serviços de back-end e bancos de dados**. Gosto de entender o problema por trás de cada projeto, explorar diferentes tecnologias e transformar o aprendizado em algo que possa ser testado, usado e melhorado.

Minha jornada passa pelo desenvolvimento para **Android e iOS**, pela criação de interfaces web e, cada vez mais, pelo back-end e pela manipulação de dados com Python.

> **Meu objetivo:** continuar evoluindo como desenvolvedor e criar projetos úteis, bem pensados e com espaço para crescer.
